Información Básica de Infraestructura

Componentes esenciales para el despliegue y administración de servidores empresariales

Active Directory (AD DS)

Servicio de directorio que centraliza la gestión de usuarios, equipos, políticas de seguridad (GPO) y Unidades Organizativas (UO) dentro de un dominio de red, permitiendo delegar permisos de forma granular.

Internet Information Services (IIS)

Servidor web flexible y seguro de Microsoft diseñado para alojar sitios y aplicaciones web. Gestiona peticiones HTTP/HTTPS desde el directorio raíz (habitualmente C:\inetpub\wwwroot).

Escritorio Remoto (RDP)

Protocolo propietario que permite administrar gráficamente un servidor a distancia utilizando por defecto el puerto TCP 3389, facilitando tareas de mantenimiento y despliegue.

Problemas Frecuentes y Soluciones

Haz clic sobre cada incidencia para desplegar su diagnóstico y resolución

1. Error 403.14 - Forbidden al abrir el sitio en Localhost
Problema

Al ingresar a http://localhost/grupo/usuario/, IIS muestra un error indicando que el servidor está configurado para no mostrar una lista del contenido del directorio.

Solución

Verifica que el archivo principal se llame exactamente index.html y que no esté dentro de una subcarpeta adicional creada al clonar el repositorio. Si clonaste una carpeta extra, mueve los archivos a la raíz de tu carpeta personal.

2. El usuario creado en Active Directory no puede iniciar sesión por RDP
Problema

El cliente de Escritorio Remoto rechaza el acceso indicando que la cuenta no tiene autorización para iniciar sesión de forma remota.

Solución

En Usuarios y equipos de Active Directory, abre las propiedades del usuario, ve a la pestaña Miembro de y asegúrate de agregarlo al grupo Usuarios de escritorio remoto (Remote Desktop Users).

3. Comando "git" no se reconoce en la consola CMD
Problema

Al ejecutar git clone en el símbolo del sistema del servidor, aparece el mensaje de que el comando no se reconoce como un programa ejecutable.

Solución

Cierra y vuelve a abrir la ventana de CMD para refrescar las variables de entorno. Si persiste, verifica que la ruta C:\Program Files\Git\cmd esté agregada en la variable Path del sistema.

4. Advertencia de seguridad de certificado al conectar por RDP
Problema

Windows muestra una alerta naranja o amarilla indicando que no se puede comprobar la identidad del equipo remoto.

Solución

Es un comportamiento normal en servidores de laboratorio con certificados autofirmados. Verifica que la dirección IP coincida con la asignada por el administrador y haz clic en Conectar / Sí.
